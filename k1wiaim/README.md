# K1WI AIM

Aim trainer inspirado en aimtrainer.io — hecho como PWA de un solo sitio, sin backend.

## Subir a GitHub Pages

1. Crea un repo nuevo en GitHub (ej. `k1wi-aim`).
2. Sube estos archivos a la raíz del repo:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icons/icon-192.png`
   - `icons/icon-512.png`
3. En el repo: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root)**.
4. Espera 1-2 minutos, tu URL quedará como:
   `https://TU-USUARIO.github.io/k1wi-aim/`

## Instalarla en la barra de tareas de Windows

1. Abre la URL de GitHub Pages en **Chrome** o **Edge**.
2. Click en el icono de instalar de la barra de direcciones (⊕ o el icono de monitor con flecha), o menú (⋮) → **"Instalar app"** / **"Apps" → "Instalar este sitio como una app"**.
3. Se abre como ventana propia con su icono — dale click derecho al icono en la barra de tareas o en el menú inicio y elige **"Anclar a la barra de tareas"**.

Listo, funciona igual que tu app de Yin Yang: local, sin servidor propio, solo GitHub Pages sirviendo los archivos estáticos.
